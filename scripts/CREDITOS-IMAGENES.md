# Créditos de las imágenes de demostración

`npm run seed:demo` asigna a cada producto una foto de [Wikimedia Commons](https://commons.wikimedia.org). La plataforma no copia los archivos: los productos guardan el enlace a la miniatura de Commons.

Todas tienen licencia libre. Las licencias Creative Commons BY y BY-SA exigen citar al autor, la licencia y la fuente, como se hace aquí. Las fotos se usan solo para ilustrar productos ficticios: las marcas que aparezcan en ellas no tienen relación con NexusMarket.
